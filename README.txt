OriginalVault — News + Copyright Archive (প্রাথমিক ওয়েবসাইট)

চালানোর নিয়ম:
1. ZIP ফাইলটি Extract করুন।
2. index.html ফাইলটি ব্রাউজারে খুললে নমুনা ওয়েবসাইট দেখা যাবে।
3. নাম/লেখা বদলাতে index.html সম্পাদনা করুন।
4. নমুনা সংবাদ ও ভিডিওর কার্ড বদলাতে app.js সম্পাদনা করুন।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এটি একটি static front-end starter। এখনো অনলাইন অ্যাডমিন লগইন, সার্ভারে ভিডিও আপলোড,
  ডেটাবেজ, সার্চ, ব্যবহারকারী-নিয়ন্ত্রণ বা ব্যাকআপ যুক্ত নেই।
- প্রকাশ্যে ওয়েবসাইট চালাতে hosting-এ ফাইলগুলো deploy করতে হবে।
- বড় ভিডিও সরাসরি ওয়েবসাইটে চালাতে আলাদা video/object storage ও bandwidth লাগবে;
  ফ্রি প্ল্যানের সীমা থাকতে পারে।
- কপিরাইট আর্কাইভের রেকর্ড সহায়ক প্রমাণ হতে পারে, কিন্তু এটি নিজে সরকারি নিবন্ধন নয়।
